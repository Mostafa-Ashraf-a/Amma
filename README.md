# مشروع "جزء عم - مسار الأبطال" (Juz Amma Kids App)

تطبيق تفاعلي مصمم لتحفيظ القرآن للأطفال بأسلوب ممتع يعتمد على الألعاب (Gamification) والذكاء الاصطناعي التفاعلي.

## ✨ المميزات:
- **خريطة عالم الأبطال**: خريطة تفاعلية مدعومة بمحرك `Phaser.js` مع تأثيرات حركية جذابة.
- **تحديات متدرجة**:
    1. **تحدي الاستماع 🎧**: مزامنة نصية بصرية دقيقة مع صوت الشيخ.
    2. **تحدي الترديد 🗣️**: نظام "صدى" ذكي مع حساس ميكروفون تفاعلي.
    3. **تحدي التسميع 🎤**: محاكاة تقييم الذكاء الاصطناعي مع كشف الكلمات الحقيقي.
    4. **تحدي اللغز 🧩**: ترتيب كلمات الآيات عن طريق السحب والإفلات.
- **حفظ سحابي (Firebase)**: يتم حفظ نقاط الـ XP والمستوى والتقدم في قاعدة بيانات Cloud Firestore لضمان عدم ضياع الإنجازات.

## 🚀 التقنيات:
- **Frontend**: HTML5, Vanilla CSS, JavaScript (ES Modules).
- **Engines**: Phaser.js (Map), GSAP (Animations), Howler.js (Audio).
- **Backend**: Firebase Cloud Firestore (Cloud Sync).

## 🛠️ طريقة التشغيل والرفع:

### 1. الإعداد المحلي (Development):
يتطلب المشروع وجود `Node.js`.
```bash
# تثبيت التبعيات
npm install

# تشغيل المشروع محلياً
npm run dev
```

### 2. الرفع على السيرفر (Production):
المشروع جاهز للرفع على منصات مثل **GitHub Pages**, **Vercel**, أو **Netlify**.

#### الرفع على Vercel (الموصى به):
1. اربط حساب GitHub الخاص بك بـ Vercel.
2. اختر المستودع (Amma).
3. سيقوم Vercel تلقائياً بالتعرف على الإعدادات والرفع فوراً.

#### الرفع اليدوي:
قم برفع الملفات التالية فقط إلى السيرفر الخاص بك:
- `index.html`
- مجلد `js/`, `css/`
- ملف `quran-sync.json`
- أي أصول أخرى (Assets).

## ⚠️ ملاحظة هامة (Firebase):
تأكد من تفعيل **Cloud Firestore** في لوحة تحكم Firebase واختيار **"Start in Test Mode"** لكي يتمكن التطبيق من حفظ التقدم بنجاح.
