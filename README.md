# مشروع مبدئي لتطبيق "جزء عم - مسار الأطفال" (Prototype)

هذا المشروع عبارة عن نموذج أولي تفاعلي يعرض فكرة تطبيق تحفيظ القرآن للأطفال بأسلوب الألعاب (Gamification). 

## التقنيات المستخدمة:
- HTML5, CSS3, Vanilla JS.
- **Phaser.js**: لرسم وتجهيز خريطة اللعب التفاعلية (المسار والقرى).
- **GSAP**: لعمل حركات وانسيابية في الواجهات وشريط النقاط (XP).
- **Howler.js**: للمؤثرات الصوتية.
- **json-server**: لمحاكاة سيرفر وقاعدة بيانات وهمية للـ Backend.

## طريقة التشغيل:
لكي يعمل النموذج بشكل صحيح (خاصة جلب البيانات من الـ json-server)، اتبع الخطوات التالية:

1. تأكد من وجود `Node.js` مثبتاً على جهازك.
2. افتح الطرفية (Terminal) في مسار المشروع.
3. قم بتثبيت التبعيات (Dependencies):
   ```bash
   npm install
   ```
4. قم بتشغيل خادم الويب و خادم واجهة برمجة التطبيقات (API/Backend) معاً:
   ```bash
   npm run dev
   ```

ستعمل واجهة المستخدم على الرابط: `http://localhost:3000` (حسب المخرجات في التيرمينال، غالبا سيرف ياخذ بورت آخر مثل 3000 أو 5000 ولكن `concurrently` سيعرض لك البورت الصحيح).

## الملاحظات:
- تم تصميم الواجهة لتبدو كتطبيق موبايل (محددة العرض) للحفاظ على تجربة الموبايل وعرضها في المتصفح.
- عند محاولة تسجيل الصوت في أي قرية (مرحلة) مفتوحة، هناك نظام محاكاة مدته ثانيتين ينتظر تقييم الذكاء الاصطناعي ثم يعطي التقييم الإيجابي.
